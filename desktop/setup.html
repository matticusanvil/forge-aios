Forge AIOS

Let’s get you set up

Four quick steps. Forge AIOS runs Claude Code on this computer, signed in with your own Claude account.

  1. 1
    Install Git
    Claude Code uses it to run commands and track changes.
  2. 2
    Install Claude Code
    Anthropic’s official installer, a few minutes.
  3. 3
    Sign in to Claude
    A Claude Code window opens: choose your Claude account (Pro, Max, Team or Enterprise) or an API key, and follow its steps. Forge never sees your sign-in.
  4. 4
    Choose a folder for your projects
Forge AIOS is free and open source, and isn’t made by Anthropic. Claude usage is billed to your own Claude plan or API key.
